# ELS Observation Companion

Blank, offline-capable Early Learning lesson observation tool and proposed rubric for heads to review. Seven standards and five observer-selected ratings, with 35 descriptors and examples. No automatic overall score.

Observation data remains in the browser tab until deliberately downloaded. No analytics, remote runtime dependencies or automatic personal-data storage. Draft JSON and Excel exports are unencrypted: use school-managed secure devices and approved file storage. Do not commit observation records to this repository. SuccessFactors remains the official record; Excel output is a manual entry aid, not a verified import.

## Use

Open the GitHub Pages site online once and wait for the offline-ready message. On iPhone/iPad use Safari Share > Add to Home Screen, open the installed app online once, then test a fresh launch in airplane mode. Actual mobile installation and native save/reopen require a school device pilot; desktop responsive checks do not confirm mobile offline operation.

Laptop: download offline-laptop.html and open it in a current desktop browser. Save your draft deliberately before closing; unsaved work can be lost. Clear observation clears the active tab only, not downloaded files.

## Rubric

Draft for internal calibration, informed by South African NCF, NAEYC DAP, England Development Matters and New Zealand Te Whāriki. References and context are included in the app. These frameworks do not define or endorse this employee-rating scale. Moderate judgements before consequential use. Not Observed means insufficient evidence, never zero performance.

## Offline package

Relative manifest, service-worker and asset paths support deployment under this repository subpath. The service worker caches app assets only. Hosting receives ordinary asset requests; observation values are never sent. Native mobile and native Excel rendering remain pilot checks.
